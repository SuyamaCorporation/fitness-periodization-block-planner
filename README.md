# Fitness Training Periodization Block Planner

Plans 8, 12, or 16-week periodization training cycles, dividing them into colour-coded Accumulation, Intensification, and Realisation/Peak blocks with volume and intensity targets per week.

## Key Features

- Four goal/sport presets: Strength, Hypertrophy, Endurance, General Fitness — each with distinct volume/intensity profiles per block
- Automatic block assignment (Accumulation → Intensification → Realisation) based on total weeks and chosen peak week
- Weekly table showing date, block type (colour-coded green/yellow/red), volume %, intensity %, and sessions per week
- Per-week notes field for custom training annotations, persisted in localStorage
- CSV export of the full plan including notes
